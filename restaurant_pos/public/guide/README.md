# دليل استخدام RPOS

هنا تلقى شرح كل شي تحتاجه عشان تشغّل مطعمك على النظام، من أول تجهيز لين إقفال اليوم.
كل صفحة تشرح شغلة وحدة بخطوات قصيرة.

الدليل مقسوم حسب الأهمية: ابدأ بالقسم الأول، وما بعده خذ منه اللي يخص مطعمك.
